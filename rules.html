RULESHAWKINS HOME

Правила объясняются по-русски, а каждый английский пример идёт с IPA, переводом и озвучкой.

THERE IS

Используем, когда говорим об одном предмете.

There is + a/an + noun

There is a lamp on the desk./ðeər ɪz ə læmp ɒn ðə desk/На письменном столе есть лампа.

THERE ARE

Используем, когда предметов два или больше.

There are + number/some + plural noun

There are three books on the table./ðeər ɑː θriː bʊks ɒn ðə ˈteɪbəl/На столе есть три книги.

A / AN

a — перед согласным звуком: a lamp, a book, a school.

an — перед гласным звуком: an apple, an armchair, an hour. Важно: смотрим на звук, а не только на букву.

There is an armchair in the living room./ðeər ɪz ən ˈɑːmtʃeər ɪn ðə ˈlɪvɪŋ ruːm/В гостиной есть кресло.
There is a window in the bedroom./ðeər ɪz ə ˈwɪndəʊ ɪn ðə ˈbedruːm/В спальне есть окно.
